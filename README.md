# 會播放等你下課的音樂播放器 (NUCLEO-G474RE 期中專題)

快速完成這首微算機《等你下課》，讓你下課不再無聊。

## 1. 情境故事
每次快到下課時間，大家心裡都在倒數。「等你下課」這首歌寫出了等待的心情，因此我們用微控制器結合蜂鳴器與按鍵，做出一部能隨時播放《等你下課》經典主歌與副歌樂曲的掌上型音樂播放器。

## 2. 替身對照
* 蜂鳴器 (Buzzer) -> PB0 (TIM3_CH3 PWM 輸出)
* 播放/暫停按鍵 -> PA0 (GPIO Input, 上拉電阻)
* 切換樂段按鍵 -> PA1 (GPIO Input, 上拉電阻)
* 狀態指示燈 -> PA5 (板載綠色 LED LD2)

## 3. 功能與驗收條件
* 按下 PA0 按鍵可切換播放與暫停。
* 按下 PA1 按鍵可切換主歌/副歌旋律。
* 蜂鳴器依據樂譜頻率陣列精確發聲，LED 在播放時隨節奏閃爍。

## 4. 用到的技術
* GPIO：PA0, PA1 輸入偵測（帶軟體去彈跳），PA5 數位輸出。
* Timer PWM：TIM3 Channel 3 生成指定頻率方波以驅動蜂鳴器發聲。
* UART Serial (USART2)：115200 bps，經由板載 ST-LINK VCP 輸出當前播放曲目與狀態訊息至電腦終端機。

## 5. 腳位表
* PA0 = 播放/暫停按鍵 (GPIO_Input, PULLUP)
* PA1 = 切換樂段按鍵 (GPIO_Input, PULLUP)
* PA5 = 板載 LED2 (GPIO_Output)
* PB0 = 蜂鳴器訊號腳 (TIM3_CH3 PWM)
* PA2 / PA3 = USART2 (ST-LINK VCP 序列埠)

## 6. 建置與執行
1. 使用 STM32CubeIDE 開啟專案並編譯。
2. 將 NUCLEO-G474RE 連接至電腦並進行燒錄 (Run/Debug)。
3. 開啟 Serial Monitor (Baud rate: 115200 bps)。
4. 按下 PA0 按鍵開始播放《等你下課》。

## 7. 程式結構
* Core/Src/main.c：包含主迴圈、按鍵去彈跳處理、音樂頻率陣列定義與 PWM 週期更新函式。
